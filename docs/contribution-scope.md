# Project Ownership, Contributions, And Result Data

The Young's modulus instrument was a five-person competition project. The contribution split relevant to this repository is:

| Member | Main contribution |
|---|---|
| 丁庆祥 | Online pre-lab and remote-learning software. |
| 朱兆兴 | Mechanical structure. |
| 田秉卓 | Offline C# instrument program and measurement-principle design; repository maintenance. |
| 郭智美 | Measurement-principle design and data processing. |
| 赵思梦 | Measurement-principle design and data processing. |

## Material Map

- `app/YoungsModuleTest/` contains the offline program by 田秉卓.
- `docs/source-materials/` preserves reviewed team Word/PPT documents.
- `docs/assets/` contains images extracted from those team documents.
- `simulations/` contains later hardware-independent explanations written for this repository, not the original control program.
- The online pre-lab software by 丁庆祥 is a separate contribution and is not represented by source code here.

## Result Data

The repository omits the team's numerical result tables because measurements vary with wire condition, loading, optical alignment, CCD scaling, and calibration. The published material explains the model, acquisition flow, and fitting method so a new setup can be calibrated and evaluated on its own terms.

# 项目署名、分工与结果数据

杨氏模量实验仪由五人团队共同完成。与当前仓库相关的分工如下：

| 成员 | 主要贡献 |
|---|---|
| 丁庆祥 | 在线预习与远程学习软件。 |
| 朱兆兴 | 机械结构。 |
| 田秉卓 | 线下 C# 仪器程序和测量原理设计；仓库维护。 |
| 郭智美 | 测量原理设计与数据处理。 |
| 赵思梦 | 测量原理设计与数据处理。 |

## 材料对应关系

- `app/YoungsModuleTest/` 为田秉卓负责的线下程序。
- `docs/source-materials/` 保存已审核的团队 Word/PPT 文档。
- `docs/assets/` 为从团队文档中提取的图片。
- `simulations/` 是后续为仓库阅读编写的不依赖硬件的说明，不是原始控制程序。
- 丁庆祥负责的在线预习软件是独立贡献，当前仓库没有上传其源码。

## 结果数据

仓库不公开团队的数值结果表，因为测量会随钢丝状态、加载、光路对准、CCD 比例和标定变化。公开材料保留物理模型、采集流程和拟合方法，便于新的装置独立标定和评估。
